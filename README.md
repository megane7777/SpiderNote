# SpiderNote — GitHub Pages版

ダークテーマのスパイダーマップ／知識整理アプリです。静的ファイルのみで動作し、GitHub Pagesで公開できます。

## GitHub Pagesで公開
1. GitHubでPublicリポジトリを作成します。
2. `index.html`、`style.css`、`app.js` をリポジトリ直下へアップロードします。
3. Settings → Pages → Build and deployment で `Deploy from a branch` を選択します。
4. Branchを `main`、Folderを `/(root)` にしてSaveします。
5. 公開URLを開きます。

## 実装機能
- 複数マップ、フォルダ、お気に入り、複製、アーカイブ、ゴミ箱
- ノードの追加・編集・移動・複製・削除
- ノードの親子関係、子ノードの折りたたみ／展開
- ノード画像、説明、アイコン、色、形、サイズ、枠線、影、透明度、タグ
- 普通の線・矢印・双方向矢印、ドラッグ接続、接続解除
- マップ同士の双方向関連付け、関連先への移動、関連解除
- 放射状・ツリー・グリッド・分散配置
- マップ／ノード検索、タグ・説明を含む検索
- 元に戻す／やり直す、マップごとの変更履歴（最大100件）と履歴復元
- 拡大縮小、全体表示、ミニマップ
- JSONバックアップ／読み込み（追加・全置換）、PNG出力、印刷画面からPDF保存
- PC・スマートフォン向けレスポンシブ画面
- 操作ガイド、自動保存

## 保存と同期の重要な制約
- マップデータはブラウザの `localStorage` に自動保存されます。
- ブラウザや端末をまたいだ自動同期、アカウント、クラウドバックアップは含みません。
- GitHub Pagesは静的ファイルの公開サービスであり、マップデータを保存するデータベースではありません。GitHub Pagesだけという条件を維持したまま、複数端末の自動同期を実現することはできません。
- 端末間でデータを移す場合は、JSONバックアップをエクスポートし、別端末でインポートしてください。
- ブラウザのサイトデータを消去すると保存内容が失われる可能性があります。定期的にJSONを別の場所へ保管してください。

- `style.css`：デザインとレスポンシブ表示
- `app.js`：マップ編集・保存・履歴などの処理
